# The Last Signal as a horror RPG

## The promise

This is not a shooter wearing horror art, and it is not a corridor haunted-house. The player inhabits Mara Venn: an engineer returning to a station where her past choices helped create the threat. Progress should make Mara more capable and more implicated, while the Resonant stays frightening.

## Current playable RPG layer

- **Mara progression:** choose one opening specialty in Mara's Field Kit, then gain XP from exploration, logs, repairs, companion moments, and milestones. Later levels award one skill point.
- **Build choices:** `Quiet Step` reduces movement noise, `Charged Pulse` extends scavenger stun time, and `Insulated Pack` reduces flashlight damage.
- **Quest journal:** the Character screen shows Mara's level, current main objective, and Nix's optional companion quest.
- **Companion dialogue:** Nix now has a conversation rather than a one-button trade. Feeding it builds trust; asking it about the Resonant yields a practical survival hint.
- **Narrative agency:** the beacon offers a choice to contain the Resonant with Echo Lock or broadcast Project Echo's records.

## Core gameplay loop

1. Explore a station district and pursue a character-driven quest.
2. Talk, inspect records, or help an ally to learn more and gain XP/resources.
3. Choose an approach: move quietly, hide, vault, spend a scarce arc pulse, or use sound as bait.
4. Improve Mara in a way that changes that approach.
5. Resolve an objective with a story consequence, then enter a more dangerous district.

## What comes next

The most valuable expansion is not more generic loot. It is three dense station districts with competing quests: recover Soren's evidence, earn Nix's route through the vents, or reinforce Echo Lock. Each should offer different rewards and alter which route or ending detail is available.
